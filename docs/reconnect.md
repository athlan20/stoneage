# 断线与重新登录（STAGE-140）

断线保留内存中的世界资料、背包、宠物、任务、百科与消息，顶部持续提示“离线 · 资料可能过期”。所有服务器查询和游戏操作被拦截；自动战斗停止，旧 NPC 窗口、交易、确认、目标与在途提交全部作废。已发但未回的操作提示“结果未知”，不会重发。战斗快照冻结，不在本地推进回放或结算。

场景 Esc → 游戏菜单 → 系统 → 重新连接。战斗快照中 Tab 打开系统。重新连接要求重新输入密码，真实执行连接、hello、login、characters、enter_world；旧连接代次作废。密码错误可重试，Esc 返回原只读资料。线路、账号或角色变化时丢弃旧上下文。

同一角色进入成功后，继续刷新地点、地图、背包、宠物、任务、本地图 NPC；有战斗时查询最新战场。全部成功前保持只读，任何一步失败返回旧资料并给出实际错误。成功后使用服务端最新位置、状态、控制权与物品等资料，保留可浏览的页面和本地百科；自动战斗保持关闭。旧窗口、旧出招及交易不恢复。

TCP 与 WebSocket 共用这条状态流程，不新增传输或会话恢复令牌。不保存密码、agent 令牌原文或离线游戏数据文件。

验收包含真实 TCP 中继断流、错误密码、另一会话修改位置后重新认证与完整刷新、停服提示、旧代次事件隔离及多尺寸渲染。测试服务端可用 `-shutdown-stdin`，父进程关闭标准输入后正常通知连接并清理临时 schema，兼容 Windows。
