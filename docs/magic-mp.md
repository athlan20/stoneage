# 精灵（魔法）MP 的原版来源（STAGE-224）

本文是 STAGE-224 第 1 步的查证结论。原版源码：`original-data/gmsv`；数据：`gmsv/data/itemset.txt`（GBK，用 `LC_ALL=C grep -a` / Python 按 GBK 解码）。

## 结论

**原版没有“精灵编号 → MP”的固定映射。** 精灵的 MP 挂在**物品**上：物品表的 `ITEM_MAGICUSEMP`（`itemset.txt` 第 57 列，0 起算）。同一个精灵编号，装在不同物品上 MP 不同，所以不能按编号写成一个常数。

因此任务书第 2 步“能对上的精灵用原版值”无法按编号落地，本需求在这里停下，见文末“待决定”。

## 原版依据（源码行号）

| 位置 | 内容 |
|---|---|
| `gmsv/data/magic.txt` | 每行 9 列：名字,说明,函数,参数,ID,使用场所,目标,复活旗标,图标。**没有 MP 列**（已核对 181 行）。 |
| `gmsv/item/item.c:83` | 物品表的 `mid` 列对应 `ITEM_MAGICID`（精灵编号）。 |
| `gmsv/item/item.c:85` | 物品表的 `mu` 列对应 `ITEM_MAGICUSEMP`（施放 MP）。 |
| `gmsv/magic/magic.c:26` `MAGIC_Use` | 普通用精灵：`mp = ITEM_getInt(itemindex, ITEM_MAGICUSEMP)`（第 40 行），`itemindex` 是背包里这个物品。 |
| `gmsv/magic/magic.c:79` `MAGIC_DirectUse` | 直接用（如宠物/他人身上的）：同样读 `ITEM_MAGICUSEMP`（第 108 行）。 |
| `gmsv/battle/battle_command.c:351` | 战斗指令：`itemindex = CHAR_getItemIndex(charaindex, iNum)`，`iNum` 是栏位号。 |
| `gmsv/battle/battle_command.c:364` | 精灵版宠物技能（`attskill`）：`mp = ITEM_getInt(itemindex, ITEM_MAGICUSEMP)`（第 364 行）。 |
| `gmsv/char/char.c:2427` | 战斗指令 `J`（状态）把 `ITEM_MAGICUSEMP` 下发给客户端。 |
| `gmsv/item/item_gen.c:1329` | 合成物品时把 MP 从原物品复制到新物品（`ITEM_setInt(inslayindex, ITEM_MAGICUSEMP, mp)`）。 |
| `gmsv/magic/magic.c:23` | `#define MP_RATE 0.7`：`MAGIC_Use` / `MAGIC_DirectUse` 里，人物有 `CHAR_FMINDEX >= 1` 且 `CHAR_FMSPRITE` 为 0 或 1 时，对部分精灵的 MP 乘 0.7（取整）。本需求未核对这条规则的完整适用范围，服务端目前没有实现，列为待查。 |

源码里没有 `CHAR_EQUMAGIC`（已在 `gmsv`、`saac` 全部搜过，无命中）。所以 CHAR_EQUMAGIC 不是原版 MP 的来源；`tools/gen-magic.py` 头部注释里“每个人物习得的精灵表（CHAR_EQUMAGIC）”的说法不对，应改掉。

## 数据统计（itemset.txt）

- 带精灵编号（第 55 列，非空、非 -1、非 0）的物品：**7874 条**，涉及 **145 个**精灵编号。
- 出现过的 (精灵编号, MP) 组合：**241 个**；MP 取值共 **35 种**。
- **40 个**精灵编号在不同物品上 MP 不一样。例：
  - 精灵 2（治愈的精灵 Lv3）：157 件 MP 11，3 件 MP 20。
  - 精灵 71：110 件 MP 9，50 件 MP 3（净化精灵系的防具）。
  - 精灵 134（猛毒的精灵 Lv5）：基础斧头（如 `贝诺美斯Lv5斧头`，物品 81）MP 0；`里拉拉的爪`（1336）MP 2；合成斧头（物品 7749）MP 2、（7809）MP 4。
- 装备自带精灵的 MP 已经用 `ITEM_MAGICUSEMP`（`server/character/equipmagic.go`，STAGE-190），这部分与原版一致。

## 待决定（需要编排方定）

1. 人物栏位上的精灵（`givemagic` 写入 `characters.magics`）没有原版 MP 可对。选项：
   a. 维持现状（推算值，注释写明“无原版依据”）；
   b. 取物品表的众数作为该编号的 MP（表中第 4 列），不一致的 MP 另列；
   c. 管理命令发精灵时直接指定 MP。
