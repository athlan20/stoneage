# 练级路线（1 → 120，agent 执行手册）

给 agent 用的练级脚本：**按阶段（S0–S10）顺序执行**，每段有明确的进入条件、地图、目标区域判据和退出条件。
请求字段一律以 [protocol.md](protocol.md) 为准，agent 的行为规范与权限见 [agent-guide.md](agent-guide.md)。

数据出处（改过就要重算本文的等级与坐标）：

| 文件 | 用途 |
|---|---|
| `server/gamedata/encounts.tsv` | 遇敌区域（地图、矩形、CEP、人数上限） |
| `server/gamedata/enemygroups.tsv`、`enemies.tsv`、`petbase.tsv` | 敌群、等级区间、怪物名 |
| `server/gamedata/travel_catalog_gen.go` | `warp` 的准入与落点 |
| `server/gamedata/newplayerpets.go`、`newplayeritems.go` | 出生三只宠与出生礼物 |
| `server/battle/rewards.go` | 经验衰减公式 |

复核命令：`python tools/encounter-lookup.py --floor <地图号>`、`--name <怪名>`、`--lv <等级>`。

## 1. 三条硬规则（全程不变）

### 1.1 加点：体力 : 速度 = 1 : 1

每升 1 级得 3 点未分配点数（`status.skill_points`），**当场加掉，不要攒**。

判据只有一条，每次只加 1 点：

```jsonc
// 当前 体力 <= 速度 → 加体力；否则加速度。循环到 skill_points = 0
{"type": "addpoint", "data": {"stat": "vital", "points": 1}}      // 体力
{"type": "addpoint", "data": {"stat": "dexterity", "points": 1}}  // 速度
```

这条规则自然保持两项相等（最多差 1）。**不要加腕力、不要加耐久**：攻击力靠骑乘合体（人 ×0.8 + 宠 ×0.8），
防御靠骑乘分摊（`docs/ride.md` §5），体力堆血量、速度堆敏捷（敏捷 = 速度，决定出手顺序）。

### 1.2 回血：恩惠的精灵 Lv3，不买药

- 出生礼物 **马祖的棍棒**（物品 2690）在背包 5 号格，**先穿上**：`item_equip {"slot": 5}`。棍类自动进 2 号装备位（手）。
- 装备自带的精灵占用**同号精灵栏位**，所以它在 `status.magic` 里是 `slot: 2`。
  **以 `status.magic` 里 `name` 含「恩惠」的那一项的 `slot` 为准**，不要写死 2。
- 战斗中回血：`battle_command` 给 `actor: "player"` 交 `{"act": "magic", "magic": <slot>}`；
  恩惠是己方全体回复（`status.magic` 里那一项的 `target_type` 是 `ally_all`），**不用带 `target`**。
  如果该项的 `target_type` 不是 `ally_all`，按它自己写的来（要选目标就带 `target`）。
- 触发阈值：人物 HP < 最大 HP 的 50%，或宠物 HP < 30%。其余回合平砍。
- 战斗外回血：`magic_use {"slot": <slot>}`。
- 精灵耗的是装备的气、不耗人物 MP，所以可以一直用；不买药、不捡药。

### 1.3 骑乘：全程骑雷龙

出生送三只宠，栏位固定（`docs/protocol.md` 5.6）：

| 栏位 | 内容 | 说明 |
|---|---|---|
| 0 | 出生地宠 | 加加村出生 = **克克尔** |
| 1 | 配套**虎** | 格鲁西斯 / 贝鲁卡 / 金格萨贝鲁 / 贝鲁伊卡，按人物身体颜色定，只用来出战 |
| 2 | 配套**雷龙** | 布洛多斯 / 布林帖斯 / 布拉奇多斯 / 斯天多斯 / 邦恩多斯，按外形定，**只用来骑** |

- **1 级就去学骑乘**：`warp {"floor": 3030}`（加加村的庄园，落点 15,39）→ `npc_find` 找「骑乘训练师」→
  `talk` → 依次学完初级、中级、高级、特级（全部免费，`ride_level` 0→40→80→120→200）。
  **必须先学初级再学下一级**，跳级会被拒。
  **每学一级要走一遍窗口**（`talk` 只是弹出菜单，不会自动学）：`talk {"npc": 1786}`（`npc_find` 查到的编号，加加村是 1786）→
  `npc_choose {"no": 3}`（主菜单「学习骑乘宠物」）→ `npc_choose {"no": N}`（课程菜单：1 初级、2 中级、3 高级、4 特级）→
  `npc_choose {"no": 1}`（确认页「是」，确认后自动关窗，`status.ride_level` 变化并推 `notice`）。学四级就把 `talk` 起的整套重复四遍；
  选错了或弹出的是消息页（没有选项）用 `npc_close` 关掉再来。协议见 [protocol.md](protocol.md) 5.54。
- **但 1 级骑不上**：上骑要求宠物忠诚 ≥ 100，雷龙 MODAI 300，忠诚 = 人物等级 × 66 ÷ 300 × 100
  → 1 级 22、3 级 66、**5 级 110**。所以 5 级前 `pet_ride` 会回 `RIDE_LOYALTY_LOW`，**不要重试**，等到 5 级。
- 5 级后：`pet_ride {"slot": 2}`。上骑前雷龙必须处于 `rest`（出生默认就是 rest）。
  骑上后不要再对它 `pet_state`（会回 `PET_RIDING`），下骑用 `pet_unride`。
- **虎的使用时机（玩家定的经验规则）：人物 10 级之后才让虎出战**。
  - 1–9 级：`pet_state {"slot": 0, "state": "battle"}`（出生宠出战），人物骑雷龙。
  - 10 级起：`pet_state {"slot": 1, "state": "battle"}`（虎出战，出生宠转 rest），人物照旧骑雷龙。
  - 骑乘与出战可并存（STAGE-149）：雷龙合体、虎单独上格子，各打各的。

## 3. 每一站怎么打（统一流程）

agent 不能自由走路，**只能靠 `warp` 换图 + `encounter_start` 定位区域**。每一站都是这三步：

```jsonc
{"type": "warp", "data": {"floor": 10001}}                          // 1. 传送到目标地图，落在默认落点
{"type": "encounter_areas", "data": {}}                             // 2. 列出本图可选遇敌区域
{"type": "encounter_start", "data": {"source_floor": 10001,
    "area_id": "<第 2 步挑出来的 id>", "mode": "infinite"}}          // 3. 定位到区域并连场开打
```

第 2 步选区域的判据（**按顺序比较，不匹配就看下一个**）：

1. `available == true`；
2. `level_min` / `level_max` 落在本阶段的「怪等级」区间内（见总表）；
3. `enemies` 里有本阶段的「目标怪」；
4. 上面都满足时，取 `max_enemies` 最大的那个。

区域 ID 跨会话稳定，但**不要把它写进脚本**：每张地图重新 `encounter_areas` 选一次，
数据改了也不会打错区域。

打怪期间：每场 `battle_end` 按 §1.2 判断要不要补血，按 §1.1 把升级得到的点数加掉。
**每换一站私聊汇报一次**（`agent_say`），并用 `agent_plan` 更新计划进度。

  或者停止自动练级，把当前等级、位置和“已无更高区域”报告给玩家。
- 怪：奥卡洛斯、巴朵兰恩、布洛多斯、斯天多斯等。这一段血量厚、伤害高，**补血阈值提到 60%**。

## 5. 换站判据（唯一标准）

```text
经验系数 = 1                        人物等级 - 怪等级 <= 5
经验系数 = (20 - (人物等级 - 怪等级)) / 15   差值 6..19
经验系数 = 0（每只 1 点）              差值 >= 20
```

（`server/battle/rewards.go` 的 `levelDiffExp`，全额线 +5 级、每多 1 级少 1/15。）

执行规则：

1. 人物等级达到本阶段 `to` → 换下一站；
2. 或者 **人物等级 − 本区域 `level_max` ≥ 10**（经验只剩 2/3 以下）→ 提前换下一站；
3. 换了之后先打 3 场，如果升级速度比以前慢一半以上，回上一站补几级再来（说明越级了，怪打不动）。

**不要**用「打不过」当换站理由——打不过说明站选错了（`level_max` 选高了），不是等级不够。

## 6. 生存与异常

| 情况 | 处理 |
|---|---|
| 人物 HP 掉得快、一场打不完 | 换 `max_enemies` 更小的区域（上限 2–5 的），别硬吃 10 只 |
| 宠物（虎）HP 归零 | 战斗里自动不参战，战后 `pet_state` 改 rest 再改 battle 恢复；不要放生 |
| 人物被打倒 | 原地 1 血复活，遇敌计划还在，照常打（STAGE-194）；立刻补血 |
| 被打飞回城 | 遇敌计划被清（`encounter_changed` 带 `reason: "lose"`），重新 `warp` + `encounter_start` |
| `RIDE_LOYALTY_LOW` | 等级不够骑雷龙（5 级才有 100 忠诚），等升级，别重试 |
| `RIDE_LEVEL_GAP` / `RIDE_NOT_LEARNED` | 骑乘课没学全，回 3030 庄园补课 |
| `NO_ENEMY_HERE` | 当前位置不在可选区域，用 `encounter_start` 而不是 `encounter on` |
| `ENCOUNTER_AREA_UNAVAILABLE` | 区域被道具条件锁了或抽不出敌人，重新 `encounter_areas` 换一块 |
| 背包满 | 只留马祖的棍棒；掉落塞满时用 `item_drop` 丢最低价值的（有疑问先问玩家） |

## 7. 给玩家的汇报节奏

- 每次换站：`agent_say` 一句「S4 阿布洞 3F，Lv28→40」+ `agent_plan` 更新进度。
- 每 10 级：报一次等级、当前地图、经验速度（每场大概多少经验）。
- 卡住（连续 3 场没升一级、或反复被同一只怪打倒）：停下来问玩家，不要自己乱换图。
