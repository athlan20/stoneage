# 交互规范（全局）

场景页使用四列（STAGE-152 为三列，STAGE-273 加了附近玩家列）：第一列为当前地图普通出口，末尾保留“传送到其他地点 / 查找并直接对话 / 回城”；第二列为本图 NPC；第三列为附近玩家（STAGE-273）；第四列为本图遇敌区域（末尾固定「停止遇敌」）。默认第一列，←→ 切列、到两端停住，↑↓、Home/End、PgUp/PgDn 只导航当前列，四列各自保存选择和滚动位置。Enter 对出口直接通过（不二次确认）、对 NPC 沿用直接对话、对遇敌区域弹出「遇敌 1 次 / 无限遇敌 / 取消」（默认 1 次，Esc 取消且不改变位置与遇敌状态）；固定地点的原有流程仍保留。普通字母不输入，/ 命令、Esc 菜单及弹窗优先级保持。

## 焦点与导航

- 场景：←→ 切出口/NPC/附近玩家/遇敌四列，↑↓/翻页选行，Enter 直接通过出口、对话、打开附近玩家的动作面板、选择遇敌次数或打开固定入口，Tab 详情、F5 刷新焦点列（`/players` 聚焦附近玩家列并刷新）；遇敌动作面板打开时按键只归面板，Esc 先关面板；Esc 才打开游戏菜单。
- 游戏菜单：↑↓ 选择角色、宠物、背包、任务、快捷传送、社交、消息、百科、系统；Enter 进入；Esc 回场景。社交（STAGE-162）里只有「队伍」一栏：没有队伍时 Enter 直接组成分身队，有队伍时 Enter 打开成员的动作菜单（查看详情、解散队伍；解散走默认取消的确认）；名片簿、邮件仍未做；社交页的两个开关见 `docs/ui.md`「社交页的开关」（STAGE-276），`Enter` 或空格切换。
- 快捷传送（STAGE-161）：↑↓/Home/End/PgUp/PgDn 选行，Enter 进入下一级或直接传送，Esc 逐级返回、到根层再退才离开这一页。每层各记光标与滚动位置；普通字符不抢页面按键，要打命令按 `/`。选中的就是当前所在地时只提示、不发请求；传送在途时 Enter 不重复发送。根层的「1级宠物」列表里，`/` 或 `f` 打开筛选框（字符进框，Enter 应用，Esc 先清空筛选再交回列表，Backspace 只删字），与百科搜索的 Esc 规则一致（先清搜索、再退层）；NPC 目录页的 Esc 则直接回上一层，不先清搜索词。
- 练级传送（STAGE-279）：与「1级宠物」同一套按键（L1 段列表、L2 练级点、L3 落点、L4 动作），`Esc` 逐层返回，根层再 `Esc` 回快捷传送根层。
- 功能页：↑↓ 选择，←→ 换本页栏目；任务页 ←→ 切全部/进行中/已完成。Enter 打开当前对象，Esc 回菜单或来时的场景。数字页号和 Tab/Shift+Tab 换栏保留兼容入口，不是必需操作路径。
- 对象动作：↑↓ 选动作，Enter 继续；需要名字、暗号、数量、目标或确认时才进入对应步骤。Esc 回上一层，恢复对象与选择位置。
- 阅读：↑↓ 按行，PgUp/PgDn 翻页，Home/End 首尾；方向键不隐式换另一篇内容。百科搜索从可见“搜索百科”或 Tab 打开独立表单。
- 消息：↑↓/翻页浏览历史，离开再回保留锚点，End 跟随最新。

输入栏的内容不决定焦点。收起命令栏后草稿保留，但不会显示为正在编辑，不抢方向键、Enter 或 Esc；再次按 / 才继续编辑。

## 聊天输入框（STAGE-278）

公开聊天（本图、世界）的输入框是专用文字输入层，和系统页私聊同类：打开后字符进框，`Backspace` 只删字。详见 `docs/chat.md` 第三节。

- `Tab` 切频道（本图 / 世界）；`Enter` 发送，发完保持打开并清空，方便连续说话。请求在途时 `Enter` 不重复发送；失败留在框里并保留文字。
- `Esc` 关闭输入框，未发出的草稿保留，下次打开还在；`Esc` 只退这一层，回到原来的场景或菜单。
- 超过 70 个字符不能再输入（计数变红）；等级不够或冷却中，框下一行写实际原因（如「世界频道需要 5 级」「还要等 12 秒」），不弹窗。
- 入口：场景页附近玩家列底部的「聊天…」（`Enter` 打开），或命令 `say 文本` / `world 文本`（见 `docs/ui.md`）。场景和菜单里普通字符仍不接收。

## 返回键（Esc 与 Backspace）

STAGE-172 起 `Backspace` 是备用返回键，给发不出单独 Esc 的键盘用（例如 Mac 上要按 fn+Esc）。

- `Esc` 是返回键：只退最上面一层，关面板、关确认、退一层页面、回菜单或回场景。
- `Backspace` 和 `Esc` 效果相同，但只在下面的地方接管：
  - 能返回的层（游戏菜单、功能页及其详情、对象动作、快捷传送、百科分类与词条、场景的遇敌面板和详情等）：逐层返回，和 `Esc` 一样。
  - 场景根页：不做任何事。根页的 `Esc` 是打开游戏菜单，`Backspace` 不打开菜单。
- 有文字输入焦点时 `Backspace` 只删字符，不返回。文字焦点包括：命令栏、系统页的私聊与令牌备注表单、百科搜索框、丢弃数量、改名和加点表单、登录与注册的输入框、NPC 暗号输入。字删光以后再按也只是空删，不关命令栏、不退出表单。
- 战斗（包括战斗控制面板）、确认层（默认取消的确认）、NPC 对话窗口的选项：`Backspace` 不接管，不返回、不取消、不关窗，这些层的按键归它们自己。
- 提示行在能返回的层里写 `Esc/Backspace 返回`；文字焦点、战斗、确认和窗口里仍只写 `Esc`，因为 `Backspace` 在那里不是返回键。

## 输入、确认与请求

表单里的空格、斜杠、数字和中文都是文字。Tab/Shift+Tab 切字段和按钮；光标键编辑文字。天数、数量和资源范围按协议校验；出错留在当前步骤并显示实际原因。

菜单发起的丢弃、放生、跨图传送、删角色、离开世界与退出，以及商店报价确认、转让队长、请出队员（STAGE-277），都默认取消。←→ 选按钮，Enter 激活，Esc 取消。已发送的请求不假装撤回；等待真实响应时避免重复提交，键盘重复 Enter 不当成第二次操作。

组队请求弹窗（STAGE-274）是例外：焦点默认在「拒绝」，`Esc` 不是取消，而是「稍后处理」（收起窗口，请求保留到过期，不发任何请求）。它不是确认层，`←→` 切按钮、`Enter` 激活，其余按键照常。

菜单和辅助命令共享业务请求与最终校验。旧命令的 y/yes 确认仅作为兼容入口；正式菜单直接选择确认按钮。观察方的游戏操作在发送入口统一复核，纯查看、私聊、令牌及控制权管理、本地显示仍按真实权限可用。

物品、宠物、任务与 NPC 窗口都有对应版本或对象上下文。资料变更、对象移除、同槽替换、回合推进时作废旧动作与确认，退回重新选择；不把旧意图套到新对象。服务端始终做最终的权限、资源、位置、窗口和报价检查。

## 各业务入口

- 背包：对象 → 装备/卸下、使用目标、移动目的格、丢弃数量与确认、说明。
- 角色与宠物：能力项 → 加点数量；宠物 → 状态、骑乘（STAGE-243，骑着它时写「下骑」，对应命令 `pet ride <编号>` / `pet ride off`，骑乘中的状态项和放生灰掉并说明）、改名、技能、对话（STAGE-239，对应命令 `pet talk <编号>`，休息或骑乘中的宠物菜单里本地拦下并说明原因）或放生确认；宠物 → 技能 → 加工/料理 → 选材料（空格勾选）→ 确认（STAGE-208）。
- 地图与 NPC：场景可直接对话；跨图先确认传送；传送到任意正式地图走「快捷传送」目录（场景入口和游戏菜单是同一个）；目录按服务端分页取完，有查询代次隔离。NPC 选项、暗号、整数和报价由 [npc-menu-v2.md](npc-menu-v2.md) 定义。
- 任务：对象 → 攻略 / 正式 NPC 候选 / 百科搜索。任务变化作废旧动作和跨图确认，不提前发任务奖励。
- 系统：控制权、私聊、令牌、自动战斗、连续遇敌、Unicode、默认回放倍速、重新连接、信息、帮助和离开/退出，见 [system-menu.md](system-menu.md)。

## 战斗

分身队战斗里（STAGE-186）指令条第一层按 `f` 打开「分身」面板，给分身和分身的宠物指定攻击目标：`↑↓` 移动、`Enter` 或数字 `1`–`8` 选一行进入选目标（只能选敌方），`Esc` 逐层返回；指定是可选的，不选的分身按合击顺序打第一个（STAGE-312），要在队长最后一条指令之前选。回放中 `f` 仍是切换速度。

动作层是两行网格（STAGE-153）：人物 4 列 2 行（攻击、精灵、道具、防御 / 捕捉、逃跑、换宠、开始或停止自动挂机），宠物 2 列 2 行（攻击、技能 / 防御、挂机）。←→ 只在当前行换列、到边界停住，↑↓ 到相邻行同一列（那一列没有条目就取最近的有效列），都不循环。动作 → 必要的道具/精灵/宠物/技能列表 → 合法目标 → 提交；无目标动作直接提交。不可用项仍显示并说明原因。目标和可公开信息按协议，不能从原型补出隐藏HP。

STAGE-167 战场采用敌左我右，目标选择的 ↑↓ 沿同一物理列选合法站位，←→ 切前后列并取最近的合法单位。我方前列在左、敌方前列在右；跳过空位与不合法目标，到边界停住。动作网格方向键及数字编号保持不变。

Esc 从目标退到来源列表/动作；宠物阶段仅在服务端允许时回改人物指令。等待、回放和已提交动作不在本地撤销。/ 打开命令栏，回合变化清除旧目标与旧命令，迟到响应不改变新回合。

结算回放的播放方式（1× / 2× / 跳过）只在系统页设，战斗里没有快捷键（STAGE-173）；结果的 Enter、Space、Esc 对应可见“继续”，普通字母不关闭结果。开始自动挂机只开自动出招，不打开遇敌、也不改选区的遇敌次数；玩家主动停止挂机时同时关闭后续遇敌（单向联动，等权威确认后才算关闭），停止不逃跑、不结束当前这一场。连续遇敌仍是独立的真实服务端开关，可以单独停。

观察模式（agent 操控）下战斗画面按 Esc 打开游戏菜单查看各页面（STAGE-182，战斗留在后台，菜单退回场景即回到战斗，`take` 收回控制权后自动退出；自己操控时 Esc 不离开战斗）。任何玩家在战斗中都能按 Tab 打开「战斗控制」面板（观察方、离线快照同样可以，只是写操作受限）：面板打开期间按键不穿透到网格或选目标，本机自动出招和自动关结果暂停，Esc 只关面板并回到原阶段，命令栏和它的 Tab 补全仍优先。

战斗开始取消旧世界操作层，结束只恢复安全浏览页或服务端战败落点，不恢复旧交易与确认。

## 断线与终端

[断线流程](reconnect.md)：保留内存资料并持续标记离线/可能过期，停止自动出招，取消操作链；未回响应的已发操作结果未知，不自动重试。真正重新连接、认证、进入同角色并完整刷新后才恢复操作；失败可重试或 Esc 返回只读资料。切账号/线路/角色不带入旧资料。令牌原文离开一次性专页或断线即清除，不进入历史、日志或快照。

Ctrl+C 在所有屏幕打开默认取消的退出确认。80×24保证可操作，110列起可并排，120×40/200×60扩展信息；窗口过小时显示提示，网络与在线战斗计时继续。沿用 ratatui demo 的边框、16色和 Unicode 降级；保留 Windows 控制台模式修复。协议、超时和老游戏公式不因界面变化而改变。
