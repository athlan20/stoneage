# 系统菜单与在线状态（STAGE-139）

系统页用方向键和 Enter 操作，Esc 逐层返回；私聊与令牌备注是独立输入框，空格和斜杠按文字处理。令牌天数为 1–365，备注最多 32 字，最多五个有效令牌；生成与吊销默认取消，等待响应时不能重复提交。原文只在生成后的专页显示，离开即清除，不写入日志或历史；例外是 `agent` 命令（STAGE-170），它把接入说明连同令牌写进消息栏，供玩家整段复制给 agent。STAGE-171 起这段（两条分隔行之间的内容）同时写进系统剪贴板：先发 OSC 52 终端序列（SSH 远程也能写进本机剪贴板），macOS 本机另用 `pbcopy`（通过 SSH 登录时跳过，免得写进远端机器）；消息栏提示「已复制到剪贴板」，并提醒令牌在剪贴板里、剪贴板历史工具可能记下，不放心可用 `revoke` 吊销。生成失败或已有五个令牌时不写剪贴板；`token new` 不写剪贴板。

协议在 enter_world/status 世界快照和 control_changed 推送增加 agent_online 布尔值；agent 离开且控制权未变时新增 agent_presence 推送 `{ "online": false }`。旧字段及操作语义不变，服务端是在线状态的唯一来源。

观察方可以浏览、私聊、管理令牌和控制权、修改本地显示；游戏操作统一在发送入口拦截。自动挂机与自动遇敌分别显示，后者等待服务端确认；「停止遇敌」也可从场景页遇敌列末尾直接触发，两处共用同一套调度状态（STAGE-152）。Unicode 和默认回放（1× / 2× / 跳过）只对本次进程生效。

战斗中按 Tab 打开的是「战斗控制」面板（STAGE-153），**任何玩家都能打开**，不只是观察方：标题写「战斗控制 · agent 在线/离线 · 玩家操控/agent 操控中」，行表只留控制权、私聊、自动挂机、停止自动遇敌、显示与回放、连接、帮助、退出，底部提示 `↑↓ 选择 · Enter 执行 · Esc 关闭面板 · / 命令`。打开时光标落在「自动挂机」那一项上。

- 自动挂机项的名字固定为「自动挂机」，后面跟 `：开 / 关`（和「Unicode：开」同一个写法），Enter 切换；关着按 Enter 开始，开着按 Enter 停止，停止走统一动作（`battle/halt.rs`），会同时关闭后续遇敌并等权威确认，请求在途时显示「（正在关闭自动遇敌）」，此时按 Enter 只提示等待，不会反向下令开启。
- 「默认回放」（STAGE-173）三档循环：`1×` → `2×` → `跳过` → `1×`。选「跳过」时下完指令就直接结算、进下一回合，不播回放动画；战斗中不再有 `Space` / `f` 快捷键。
- 遇敌项在战斗中写「自动遇敌」，后面跟 `：开 / 关 / 正在关闭`，Enter 只停止遇敌（开着时）；战斗中不提供“开新的遇敌”，避免抢走这一场。关闭失败或超时，面板最后一行用红色写出「停止自动遇敌失败：原因（Enter 重试…）」，这就是重试入口；面板外的时间线仍可在消息栏里回看。
- 「自动战斗设置」（STAGE-173）在面板里排第 8 项，进入的是和顶层「自动战斗」页同一块五栏编辑器；面板打开期间本机自动出招仍然暂停。
- 观察方的挂机和遇敌项带「（需收回控制权）」；离线快照里的写操作同样被拦，只能看和重连。面板打开期间本机自动出招和自动关结果暂停，Esc 只关面板并回到原来的阶段。
