# STAGE-148 普通出口（协议 5.48 / 5.49）

## exits（查看，in_world，player / agent 均可）

只读角色当前地图。响应 `{"floor":2000,"exits":[],"server_time_ms":0,"next_change_ms":null}`。
`floor` 是读取时的地图；`server_time_ms` 是服务端 Unix 毫秒，`next_change_ms` 是列表下一次可用状态变化的 Unix 毫秒，没有变化为 null。

每项包含 `id`、`to_floor`、`to_name`、`trigger_cells:[{"x":74,"y":33}]`、`time_gate`（all/morning/noon/night）、`available`、`unavailable_reason`（可用为 null）、`one_way`。
名字缺失用“地图 #floor”。触发格按 x、再 y 排序；显示代表格及多格数量，详情可读全部格。

## use_exit（操作，in_world，player / agent 均可，必须拥有控制权）

请求 `{"source_floor":2000,"exit_id":"稳定ID"}`，不接受客户端目标坐标。服务端在一次角色操作锁中检查控制权、非战斗、当前地图、出口归属、数据和游戏时段。
无需步行、距离、费用或二次确认，朝向不变。代表格固定为 x、再 y 最小的源格，使用它原始记录对应的目标坐标，绝不使用通用落点。

成功回复 `{}`；先推送 `position_changed`，再关闭旧 NPC 窗口，再关闭遇敌开关，玩家和 agent 收到一致位置；客户端收到权威位置后更新地图并停止自动动作。
失败没有位置、窗口、遇敌副作用。缺失/类型错：BAD_REQUEST；地图变化：POSITION_CHANGED；未知/其他地图出口：EXIT_NOT_FOUND；关闭或冲突：EXIT_UNAVAILABLE（message 说明原因）；战斗 IN_BATTLE；控制权沿用 CONTROLLED_BY_AGENT / CONTROLLED_BY_PLAYER。

## 数据和时间

普通出口只来自 mapwarp.txt，排除同地图传送、缺图、越界、未知类型/参数；不推断反向门，不含 NPC/船/任务传送。原始类型、时段、附加参数和每格目标坐标保留在生成表。
完全重复去重。同源、同目标 floor、同类型/时段/参数的四邻接连通格归并，不能合并对角格或不相连的门。同源格同条件存在不同目标时：若所有目标在同一张地图且两两曼哈顿距离 ≤1（STAGE-261），取原版 mapwarp.txt 中行号最小的一条（原版服务端遍历到第一个匹配即停），其余记录不生效，口子可用；否则所有受影响口子显示但禁用，不能任选目标。
ID 用源/目标地图、条件及代表格内容生成；列表按目标 floor、代表 x/y 排序。重排源行或加入无关记录不改变 ID、顺序及落点。
单程仅表示“按普通出口表判断”：目标地图没有任何返回源地图的有效普通边；有时段限制回边也不算单程，冲突边不充当可靠回边。

复用现有游戏时钟纪元 912766409+5400，游戏日 5400 秒、1024 时刻。NULL 全天；M：700<h≤930；A：h>930 或 h≤200；N：300<h≤700；黄昏 200<h≤300 三种门均关闭。
查询返回下一次实际状态变化时间，客户端到期重查；执行时重新检查，不相信查询缓存。

客户端按响应 id 关联地图/位置世代和连接；换图立即作废旧列表，A→B→A 的旧结果也丢弃。出口、NPC 分别有加载/失败/空状态；重连完整刷新前只读。无出口/失败时左列固定入口仍可浏览。旧 warp place/floor、按名传送、查人、回城行为保持。
