# CLI 交互原型

在浏览器中打开本目录的 `index.html` 即可体验。不需要编译、安装依赖、启动服务端或连接数据库；支持直接通过 `file://` 打开。

本目录是独立的 HTML / CSS / JavaScript 原型，没有修改 `client/src/`、Rust 客户端行为或游戏协议。所有账号、令牌、物品、数值、奖励、战斗和连接都是本地模拟。

讨论记录见 [CLI 交互调整方案](../../docs/cli-ui-redesign.md)，改造前的实际行为见 [现有 CLI 交互梳理](../../docs/cli-ui-current.md)。方案尚在体验确认阶段，当前正式客户端仍遵循原交互规范。

## 操作

- 默认焦点在当前场景或菜单。方向键选择，Enter 进入或确认，Esc 逐层返回；场景根界面的 Esc 打开游戏菜单。
- 左右键切换背包、角色、任务等页面的分类。战斗动作按画面上的网格选择。
- 文字和数量只在专门的输入框里填写。Tab / Shift+Tab 切字段与按钮，Enter 提交，Esc 取消当前表单。
- `/` 打开命令栏；Esc 收起并保留草稿，支持历史与简单补全。菜单与命令改变同一份模拟状态。
- PgUp / PgDn 翻长列表和说明；Home / End 到首尾。
- 战斗回放时 Space 跳过，f 切换倍速；结果窗口需要明确确认继续。
- 鼠标可点选菜单，底部也有可点击的模拟按键。

游戏没有手动行走。选择地点直接传送；从任务或 NPC 列表直接对话，跨地图时先确认传送，再自动开始对话。

## 建议体验顺序

1. 使用已填好的示例账号登录，选择“小明”进入游戏。也可以直接点“直接体验示例角色”。
2. Esc → 背包 → 小斧头 → 装备；左右切到装备分类查看结果。
3. 使用回复药，选择角色或宠物；移动物品时可以选空格，也能交换格子。
4. 丢弃物品、放生宠物，检查默认取消、数量输入和确认流程。
5. 找村长接受委托，再交付背包里准备好的漂亮石头。
6. 任务 → 海风的暗号 → 直接对话，确认传送后输入“海风”。
7. 找商人，完成购买、出售、数量、总价、确认；找治疗师恢复角色和宠物。
8. 传送到近郊，体验人物动作、精灵、道具、目标选择、宠物动作、Esc 修改人物指令、倒计时、回放、结果。
9. 系统 → 交给 agent，尝试操作，收回控制权后继续；再体验自动战斗、令牌、私聊、断线和重连。
10. 返回选角，选择空栏位，走完外形、名字与点数、出生地三步；删除角色需要完整名字确认。

右侧的“跳到体验场景”可以直接进入相应流程，免去重复导航。它是原型测试工具，不是未来 CLI 的一部分；跳转会结束当前测试中的战斗、恢复模拟连接与玩家控制权，保留已有游戏数据。

## 状态与边界

- 进度保存在浏览器本地存储，可用“重置全部示例数据”恢复。不同浏览器、`file://` 和不同预览地址的存储可能互相独立。
- 密码不保存、不发送，注册和登录只校验输入体验，任意合规账号都可使用同一份本地示例资料。它们不模拟真实的多账号认证与账号隔离。
- 两个角色的背包、位置、能力等游戏进度分别保存；关闭页面时正在进行的战斗不保留，下次从登录页开始。
- 常规动作在明确确认动作或目标后立即执行；丢弃、放生、删除、购买、出售等使用单独确认步骤。
- 战斗数值采用方便验收的固定模拟规则，包含捕捉、逃跑、换宠、治疗、胜负和奖励；不代表正式服务端公式。倒计时不会因为打开命令栏而暂停。
- agent 在战斗里模拟自动出招，私聊返回固定回复；不会调用任何真实 AI 服务。假令牌没有授权能力。
- 社交沿用当前项目“未开放”的状态，未增加组队、玩家交易或邮件等尚未定义的玩法。
- 只模拟当前需求的核心交互。局部地图行走、真实网络和正式游戏逻辑均不在本原型内。

## 文件与验证

- `index.html` / `style.css`：原型外壳与终端风格。
- `data.js` / `engine.js`：示例数据、导航栈与共享状态。
- `actions.js` / `npc.js` / `battle.js`：物品宠物、NPC 商店任务、战斗。
- `forms.js` / `screens.js` / `render.js` / `app.js`：表单、页面、渲染和键盘入口。
- `commands.js`：命令入口，复用已有模拟动作。
- `prototype.test.cjs`：可运行 `node --test client/html/prototype.test.cjs` 验证主要流程。

如果浏览器对本地文件有限制，也可以在此目录运行 `python -m http.server 8766`，再打开 `http://127.0.0.1:8766/`。此步骤不是运行原型的必要条件。
